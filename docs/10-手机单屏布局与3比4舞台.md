# 手机单屏布局、滚动文案与吸底操作栏

日期：2026-10-20。适用范围：宽度不超过 650 CSS 像素的手机 Web；桌面保留左右绘本布局。

## 页面结构

顶部导航固定占 48 像素，中间区域依次放置演出画面、当前页文案、陪伴选项，底部操作栏吸底。页面使用动态可用视口高度与系统安全区，整页不纵向滚动；地址栏改变高度时重新分配空间。

- 标题靠近顶栏，实际插画紧接标题下方，间距 6 像素；取消原先竖长的 3:4 纸色画框，避免横向插画贴底后在上方留下大片空白。
- 插画优先按可用宽度展示完整的 3:2 原图；屏幕较矮或有更多互动控件时，按剩余高度等比缩小，左右空余区域保留纸色。
- 文案和选项位于插画外，画面、字幕、工具和按钮各占独立空间。收紧画面省下的高度全部分给文案与选项，不再限制在原先的小字幕框内。
- 底部“重听 / 暂停、帮助（需要时）、继续”始终位于可用视口底部，系统安全区留在栏下，不覆盖正文。
- 手机的两个陪伴选项纵向排列，每项至少 56 像素高，保留动作名称、简短说明、选中状态；选中后由底部按钮确认。
- 画面标题独立一行，避免遮挡角色。

顶栏为“上一页 / 幕次 / 书架 / 更多”；第一页的上一页置灰。书架停止声音并保留当前逻辑页面与互动进度；续玩从该页开始，不承诺记住页内的某句话。“更多”同时暂停故事，内含继续、看完整画面、重看和家长设置。朗读模式在首页与家长设置中切换，正文只保留一个声音播放按钮。

## 文案推进

正文 18 像素、27 像素行高，不再按 36 字拆成多次“继续讲”。每个角色段落完整换行，同一页内已经讲到的段落保留；当前段落更深，之前的段落稍淡。

- 文案区自适应占满插画、工具、选项与吸底栏之间的剩余高度，不设 162 / 108 像素上限。390×760 的开场正文约为 300 像素；超出后仅文案区内部滚动，原文均可回看。
- 家长读模式点击“继续讲”追加下一段；当前页结束后显示剧情动作，未完成互动时显示剩余任务。
- 听故事模式按原配音片段追加段落。长段落根据录音进度逐步向上推，不更换原文，也不重新播放录音；这是阅读位置的近似跟随，不是逐字时间戳。
- 用户手动回看后停止自动跟随，显示“回到当前句”；点击后恢复跟随。自然滚回文案底部也可恢复。
- **进入新逻辑页时立即清空上一页文案，滚动位置归零，只展示新页首段。** 上一页、重看、书架续玩均按该页重新阅读，游戏数据保留。
- 同一页面内插画高度不随段落数量改变，避免讲下一段时点击目标随布局移动；屏幕可用高度改变时再重新分配。矮屏优先给正文和纵向选项留空间。
- “读完整页”仍使用分页弹层，文字按弹层容量分段，与正文滚动独立。

## 画面与其他页面

现有背景为 3:2 横幅；人物、道具、草丛遮挡、垫角与座位共用该坐标平面。原图与角色共同等比缩放，避免填满竖屏时裁掉左右内容。没有生成新的纵向美术。

首页保留封面、阅读方式和开始或继续入口；日记保留实际布置结果和朋友座位，正文与离屏活动建议分页阅读；家长页按声音、共玩、记录、关于切换。

日记画面独立使用日记卡片内的可用高度，不依赖故事演出区的空间预算变量，避免复用组件时被计算为零高度。

## 本地验收

打开 `http://localhost:4173/`。手机使用同一局域网中的开发服务地址，保持本地服务运行。

建议依次检查：初始文案与吸底按钮；连续“继续讲”后的滚动和回看；进入下一页清空正文；上一页保留游戏进度；两个陪伴选项纵向排列；寻物、石头和座位正常点击。
