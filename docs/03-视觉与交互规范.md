# 视觉与交互规范

版本：v0.4｜2026-10-20｜手机竖屏优先

## 1. 设计规格

目的：让儿童看清插画中的问题，让家长能够随时加入，以清晰、舒展、可停下的界面完成一个小故事。

审美方向：Organic / natural。淡彩森林、线稿角色、纸本留白、细线植物与印章式点缀。避免游戏大厅、成绩面板、密集卡片和奖励刺激。

颜色：中性纸白 #F6F5F0、灰绿 #53694F、浅奶油 #FCFBF7、细线灰 #DEDFD3、墨褐 #39392F。正文深色配浅底，状态同时用文字、形状或轮廓表达。

字体：Noto Serif SC 用于标题，Noto Sans SC 用于正文与控件；字体随构建提供，不依赖运行时远程字体。标题 28—52 CSS px，正文通常 16—18 px。正文行长由屏幕决定，不继承圆屏字数限制。

布局：手机以竖屏一列呈现；封面标题与插画错位形成书页构图，故事页上方场景、下方阅读与操作；桌面可用左右页式布局。交互场景使用固定比例坐标，不直接记录屏幕像素。

## 2. 四种页面

- 书架：首页单章封面、故事介绍、开始/继续、可切换朗读方式、家长入口与已完成日记入口。
- 故事：顶部返回/暂停、章节进度、声音；主插画；字幕及当前任务；主按钮。讨论邀请保持当前情境并清楚显示问题。
- 日记：本次真实座位与装饰、完成记录、可选离屏活动、回书架与再摆一次。
- 家长页：共玩建议、声音与动态设置、本机数据说明、素材说明、清除确认。

## 3. 触摸和反馈

关键控件至少 48 CSS px 高，寻物和摆放目标优先 64 px 以上；紧凑屏不缩小触摸目标，改用换行和纵向流动。关键动作都有文本可访问名称，键盘可激活，焦点可见。

寻物点击即收集；背景不作为目标；帮助逐步显示轮廓。垫角点击即放置。对话点选后试听，再用“就这样陪他”确认。餐具每次一件，点座位放置；选择已放置物后可点目标交换。装饰可切换、移除，不遮挡开餐动作。

只有任务完成才显示下一步；条件未满足时明确告诉用户还需要什么。不播放错误音效，不清空误触前的进度。

## 4. 声音和叙事

听故事模式自然段内连续讲述，配完整文字，下一场景由用户推进。家长读模式不自动发声。旁白、选择试听与收集反馈互斥；切后台/暂停/离开页面立即停止，恢复后用户主动继续。

Web 分镜版使用逐句本地临时录音，正式角色配音按同名文件替换；其余交互复用原固定录音，声音可用性与错误有可见提示。声音失败不能卡住故事，用户仍可手动读和操作。

## 5. 动态和异常

动效用于角色位移、转向、发言、安静陪伴、镜头推近、树叶与道具反馈；游戏期间相机和热点固定，支持系统减少动态偏好及应用内开关。无倒计时、无限提醒或高频闪烁。

插画失败显示清楚的替代场景与重试入口，物品仍可操作；存储失败允许继续玩，并提示本次可能无法保存；无效存档不静默覆盖，提供保留/明确重置选择。

## 6. 设备范围

手机验收：320、390、430 CSS px 的代表宽度、横屏、桌面；重点检查 Safari 与 Chromium。真实 iPhone、Android 和微信内置浏览器作为家庭试用前的补充实测，不用模拟器结果代替。

圆屏安全区、硬件字体与实体触摸尺寸只在硬件阶段适用，见 06。
