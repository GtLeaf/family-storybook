`src/lib/artwork.ts` 统一当前图、SVG 遮挡、角色与预取 URL，带版本参数更新浏览器缓存。封面图片完成后预取开场及续玩资源；故事页先准备当前图，再按故事顺序分批预取接下来两个不同背景和新增角色，并完成解码。切页会停止旧计划尚未开始的批次，已加载图片保留复用；预取失败清理记录，当前页可重新请求/手动重试。没有引入 Service Worker 或要求等待整章下载。

19 项单测、42 项 Playwright 浏览器测试（Chromium/WebKit）、ESLint 和 TypeScript/Vite 构建均通过。新增浏览器验证覆盖封面优先、开场预取后断网显示、寻找/小路的提前请求、背景与 SVG 遮挡缓存复用，以及预取失败后正常进入场景。已检查手机寻物截图，透明角色与背景对齐；真机与 GitHub Pages 跨地区网络耗时仍取决于实际网络。

## 走向大树的远行镜头（2026-10-20）

“去找屹耳”改成约 6.6 秒的远行：维尼与小猪由近处沿路左弯，再转向远处大树，最终停在树根旁。脚底位置与角色宽度连续变化，终点比例约为起点三分之一。篮子附着于维尼并同步移动、缩小；步伐在到达时结束。分镜数据保留起点、弯道、接近点和终点，供后续设备迁移复用。旁白及正式录音沿用现有版本。

暂停会同时冻结路径与步伐，继续接着走；重看从近处重新出发；减少动态直接显示树旁终点，下一页仍切到屹耳近景。19 项单测、Chromium/WebKit 共 10 项分镜浏览器检查、ESLint 与 TypeScript/Vite 构建通过；新增检查覆盖行走中的缩小、树旁终点、篮子归属、暂停续走、重看及系统减少动态。到达截图位于 `test-results/walk-tree-mobile-*.png`（本地验证产物，不提交）。

## 3. 试玩

运行 `npm run dev`，电脑打开终端显示的 Local 地址，同一 Wi-Fi 的手机打开 Network 地址。本地服务必须保持运行，手机与电脑需能互相访问。

构建用 `npm run build`；静态产物在 `dist/`。此次未建立公网托管、域名或云资源。
