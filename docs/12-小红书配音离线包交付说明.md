# 小红书配音离线包交付说明

本次保留角色逐句配音、互动反馈、暂停与重听、音量控制、家长读模式、故事动画及野餐日记。小红书通过独立离线入口构建，网页版继续沿用原入口。

## 规范边界：音频格式仍需平台确认

核对时间：2026-10-20。依据指定的 minitool-zip-builder 1.8.0 与[小工具在线文档](https://miniapp-sandbox.xiaohongshu.com/minitool/doc)（页面标记更新于 2026-10-13）。在线新增 AI 文本生成能力，本项目没有使用；在线文档未提供语音合成或专用音频播放 API。

官方媒体能力明确支持 `<audio>` 播放，skill 资源规则要求音频来自包内文件、禁止 `data:` / `blob:` 音频。然而官方与 skill 的文件类型白名单均未列出 MP3 等音频格式，两处声明不一致。

按本次“支持语音”的要求，交付包保留独立 MP3，通过标准音频元素离线播放，没有将音频伪装成其他扩展名，没有嵌入 Base64，也没有联网加载。**该配音包是待平台验证的试验产物，不能声称文件白名单校验全部通过或平台一定允许上传。** 如果平台拒绝 MP3，需向平台确认支持格式；当前公开能力没有已确认的替代配音方案。

## 构建与产物

需要项目现有 Node/Python 环境及 FFmpeg。运行：

```sh
npm run package:xhs
npm run test:xhs
```

- 离线目录：`dist-xhs/`
- 配音 ZIP：`artifacts/forest-story-xhs-voice.zip`
- ZIP 根目录直接包含 `index.html`，没有外层项目文件夹。
- 45 段音频重编码为 64 kbps、24 kHz 单声道 MP3，原始配音及交付源文件未修改。
- 字体、插画与依赖均在包内。字体和图标许可证原文保留在 `licenses.json`。
- ZIP 约 2.56 MiB，低于 10 MiB 上限，但高于建议的 2 MiB；主要体积来自保留的配音。

## 校验与适配

| 检查项 | 结果与限制 |
| --- | --- |
| ZIP 结构与资源路径 | 单入口、相对引用、资源齐全；不包含源码、构建配置、source map 或开发依赖 |
| 脚本形式 | 包内经典外链脚本；无模块入口、内联脚本与行内事件 |
| 语法 | 按 ES2017 / Chrome 61 构建；两份交付脚本通过 ES2017 语法解析 |
| 受限能力 | 无网页网络请求、动态代码执行、WASM、Worker、设备传感器等调用；Zod 使用解释执行路径 |
| 音频 | 45 个文件完整解码；配音、反馈音和字幕仍沿用原有流程；MP3 上传白名单未确认 |
| 存储 | 满足 9.46 版本及接口条件时先读平台缓存、串行写入；平台空记录可迁移浏览器旧记录；平台读取失败时避免覆盖原记录，异步保存失败会提示 |
| 兼容层 | 为容器单位、比例盒、Flex 间距、动态视口、inset、clamp、安全区提供局部回退；缺少 ResizeObserver、AbortController、图片 decode 时可继续体验 |
| 审计脚本 | 指定 skill 的 Node 目录审计与 Python ZIP 体积审计，另有资源、脚本、音频解码检查；辅助审计通过不代表平台验收通过 |
| 授权与隐私 | 无登录、上传、发布、摄像头、麦克风或其他新增用户权限请求 |

包内 JS 约 375 KiB、CSS 约 62 KiB，没有大型内嵌音频或数据库。没有使用 WebGL，相关 GPU 预算检查不适用。音频逐段复用同一播放器，离开页面会停止播放；减少动态效果选项保留。
