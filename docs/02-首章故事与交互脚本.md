现行逐页台词和镜头见 [新版脚本与分镜](08-新版脚本与分镜重制方案.md)，逐句重录文件见 [配音变更清单](09-新版配音变更与重录清单.md)。内容以 src/content/story.ts 为源，镜头以 src/content/storyboard.ts 为源。下面保留逻辑任务定义；“陪坐”已调整为“安静陪伴”，结尾以现有站姿角色围在垫边呈现。

## 1. 制作与播放

三位朋友：维尼、小猪、屹耳。五处故事背景：风吹乱野餐、林边寻物、通往大树、发现屹耳、背风野餐；另有独立封面；交互物件与角色单独绘制/导出。主要逻辑仍对应 S01—S09，两次亲子邀请与分支回应拥有独立内容 ID，Web 展示为 12 个状态。

听故事模式：按逐句录音连续朗读，并跟随实际播放事件推进镜头；遇到互动、讨论或场景结束等待用户操作。家长读模式以“继续讲”推进，整段文本可展开。旁白失败不阻塞。当前保存到逻辑场景，恢复后该页可重听，不保存动画中间位置。

## 2. 首章流程

| 内容 ID / Web 状态 | 台词与画面意图 | 操作与推进 |
|---|---|---|
| S01 / intro | 风吹散野餐，维尼说“杯子一定没有长脚。至少，刚才还没有。” | 来找找 |
| S02 / find | 小路上找杯子、餐巾、篮子，各有大轮廓线索 | 点一下即收集；任意顺序；三件齐全才继续 |
| S02-A / wind-talk | “你从哪里看出风来过？” | 找齐后邀请，不中断寻找；随时继续 |
| S03 / walk | 小猪提议邀请屹耳；篮子里还有一个朋友的位置 | 去大树旁 |
| S04 / worry | 屹耳担心风再来，垫子会飞、杯子会倒 | 看看怎样陪伴 |
| S05 / choice | 倾听或安静陪伴，没有标准答案 | 选中试听，独立确认 |
| S05-R / response | A：听见屹耳不想再追着垫子跑；B：安静陪伴后屹耳提议压住垫子 | 两条均进入下一邀请 |
| S05-A / companion-talk | “你想怎样被陪伴？”允许别的办法、不知道、不回答 | 继续故事 |
| S06 / stones | 篮子压一角，另外三角由孩子固定 | 点击空垫角直接放石头，无额外确认；三处齐全才继续 |
| S07 / picnic | 三份有角色标记的餐具，轮流选位置；纸花和叶片可选 | 依次点击空座位；全部放好后可选中一位朋友再点另一座位交换；装饰按钮直接可见 |
| S08 / ending | 屹耳仍安静：“风还在。不过，这里挺好的。”朋友围在野餐垫旁 | 记下来 |
| S09 / diary | 展示本次座位与装饰和事实性完成记录 | 回书架或再摆一次，不自动连播 |

## 3. 交互细则

- 寻找：重复点击已收集物不重新计数；手动帮助逐步显示轮廓和名称；约 12 秒无推进时给一次柔和轮廓提示，旁白/暂停不计时。只出现三件目标，环境点击不扣分。
- 对话：未选中时清楚说明先选择；确认后不能连点触发另一分支；下一页按钮短暂防连击。
- 固定：重复点已占用垫角无效；篮子和三石头覆盖四角，所有有效操作即时保存。
- 布置：餐具依次为维尼、小猪、屹耳；未入座的朋友不能覆盖已有朋友。全部入座后选择已放置餐具与目标可交换，不丢失、不重叠。
- 装饰：纸花与叶片分别放预设位置，再次点击可移除；不影响完成条件。
- 邀请：不记录回答、不录音、不催促；可立即继续。

## 4. 中断和结束

每次有效状态变化后尝试保存本机快照，存档版本和语义前置条件都要校验。正常关闭、刷新和返回可继续；备份恢复需告知可能回退；完全损坏保留原记录直到明确确认重新开始。

切后台、暂停菜单、家长设置停止声音；恢复主动操作后从当前段重新播放。重玩与清除单独确认，取消不会丢进度。日记的座位和装饰必须直接读取同一份状态。

离屏建议：在家中舒服角落用手边安全物品摆一场小野餐，也可以改天再玩。不要求上传、拍照或证明。
