# 多作品与多章节交互方案

日期：2026-10-20。状态：交互提案，未修改应用界面或阅读逻辑。

## 1. 内容层级

采用“书架 → 作品目录 → 章节阅读”，章节结束后留下一篇日记，再回到作品目录。一本作品可以有多个独立小故事，也可以按顺序讲述一个连续故事。

当前《风吹走的野餐》整体作为《森林故事集》的第一章，现有三幕、12 个逻辑页面及页内镜头属于该章内部结构，不能直接当成三个可独立选读的章节。目录只展示章，不展开每一幕、每一页或每个镜头。

只有一本作品时，可继续直接显示该作品入口；加入第二本后启用总书架。现在的首页封面与介绍可复用于作品目录顶部，不要求重做阅读中的布局。

## 2. 设计方向

目标是让儿童认封面、选故事，家长快速找到上次进度，阅读时保留大插画、完整段落和单点互动。

沿用自然纸张与淡彩绘本风格，基础色为纸白 #f6f5f0、奶油色 #fcfbf7、文字 #39392f、叶绿 #53694f；标题沿用 Noto Serif SC，正文沿用 Noto Sans SC，图标沿用 Lucide。不同作品用封面、插画和少量强调色表达差异，按钮和导航的位置保持一致。

手机阅读仍为单屏，文案区内部滚动，选项纵向排列，操作栏吸底。书架和目录按屏分页，避免增加一条长列表；实际屏幕不足时减少每屏内容数量，不能缩小文字或点击区域硬塞。所有主要入口至少保留 44 CSS 像素的点击范围。

## 3. 总书架

手机常规尺寸每屏最多四本，使用两列封面；矮屏可减少到两本。只显示封面、作品名及一句阅读状态，例如“读到第 2 章”或“已读 1 / 3 章”。点封面进入这本书的目录。

顶部保留一个主要入口“接着上次读”，明确写出作品及章节名称，直接返回最近一次正在阅读的逻辑页；没有未完成阅读时不显示该入口。下方的书籍选择用于换书，底部用上一屏、下一屏和页数切换，滑动只是辅助方式。

作品少时不显示空书位，不加入分类、搜索和推荐信息流。数量增长到翻页明显影响找书时，再考虑由家长使用的搜索与分类。

## 4. 作品目录

顶部是小封面、书名、简短介绍和全书进度；有未完成章节时显示“继续第 N 章”。目录每屏优先展示三章，每章包含缩略图、标题、一个简短主题或玩法提示，以及状态。

章节状态分为“还没读”“读到某一页”“已留下日记”。完成后再次回看不会把已完成标记取消。全书“已读 X / Y 章”按完成章数统计，不用阅读页位置或互动得分替代。

首次进入未读章节从开头开始；未完成章节默认继续，也可以从该章开头重玩；已完成章节进入回看入口，可看日记或再玩一次。

独立故事默认允许自由选章，不用做题或集星解锁。连续故事标注阅读顺序，默认推荐下一章；跳读时说明可能缺少前情，并允许从第一章开始或直接阅读。对尚未制作的内容不展示可点击的空章节。

“听故事 / 家长读”沿用上次设置，在作品目录中可切换，不要求每次进章重新选择；阅读页通过“更多”调整。

## 5. 章节阅读与导航

保持当前“标题 → 插画 → 文案和互动 → 吸底操作栏”的布局。一个逻辑页内可包含多个讲述段落和镜头，进入新逻辑页时清空上一页文案。互动仍在自己的故事情境中出现。

| 位置与操作 | 行为 |
| --- | --- |
| 阅读中左上“上一页” | 回到本章上一逻辑页，保留互动成果；不跨章后退 |
| 本章第一页左上“目录” | 返回当前作品目录，名称明确变成“目录”，不再显示无效的上一页 |
| 顶栏“书架” | 直接回总书架，停止声音并保存进度 |
| “更多 → 本书目录” | 退出本章并选其他章节，不丢当前章进度 |
| 底栏“继续讲” | 推进本页讲述段落，保持画面和互动位置稳定 |
| 底栏剧情动作 | 完成本页后进入下一逻辑页；互动未完成时提示剩余任务 |
| “更多 → 重玩本章” | 确认后只重置该章这次游玩，保留其他章进度和已收藏的日记 |

顶栏可显示“第 2 章 · 场景名”，页面标题继续表达当前情节；不同时堆叠作品、章、幕、镜头四级信息。“目录”与“上一页”职责明确，书架保持全局直达。

## 6. 每章结束与日记

每章形成自己的完整收尾和日记，不用等整本书读完。日记记录该章实际产生的结果，例如座位、布置、选择或发现，不强制所有章节都出现一张野餐垫。

日记页主要操作为“收好，回到目录”；存在下一章时，提供次要操作“读下一章”。不倒计时，不自动播放下一章。最后一章完成后，主要操作改为“合上这本书”，回到总书架并显示这本书已经读完。

在作品目录提供“我们的日记”，展示该书各章的完成记录。第一版每章保留最近一次日记快照；重玩时旧快照保留，新的游玩完成后再替换。退出未完成的重玩不会抹掉之前的日记，也不会取消已完成状态。

## 7. 不同作品怎样互动

复用阅读操作和基础交互能力，具体任务随剧情变化。不要让所有作品都重复“找三样东西 → 放石头 → 摆座位”。

| 交互能力 | 适合的情节 | 动作 |
| --- | --- | --- |
| 观察与寻找 | 发现线索、认识角色或环境 | 点击画面中的可见线索 |
| 选择与回应 | 决定先做什么、怎样陪伴 | 两个纵向选项，选中后确认 |
| 放置与组合 | 收拾行李、搭建住所、布置场景 | 先选物品，再点位置，不依赖拖动 |
| 顺序与因果 | 排列几个行动或事件 | 逐个点击选择，允许撤回和调整 |
| 亲子讨论 | 表达感受、观察不同观点 | 可选邀请，不录音、不评分，可直接继续 |

新章节可只用其中一两种，也可保留安静欣赏的段落。剧情分支优先改变回应和小范围演出，并回到共同主线，控制分支数量。不能把原著机械拆成翻页测验，也不因选择不同就惩罚孩子。

## 8. 进度、资源与退出

每个“作品 + 章节”有独立进度：当前逻辑页、分支、互动成果、是否完成和最近日记。另记最近阅读入口，供书架的“接着上次读”使用。完成状态、正在回看的位置和日记快照分开保存。

续读从保存逻辑页的第一段重新讲，不恢复半句话或旧滚动位置；切书、选章、退出与进入后台均停止原声音。普通退出无需重复确认，清除或重玩明确说明只影响哪一本、哪一章。

资源按所选章节准备，不在打开书架时加载整套名著。等待时显示本章封面和进入状态，失败可以重试或返回目录；不能出现可点击却没有内容的空白页。资源未完整准备前不宣称可以离线阅读。

当前单本单章进度需迁移到《森林故事集》第一章，保留已经找到的物品、陪伴选择、座位、装饰与完成记录。第一版继续本机保存，不因内容变多就要求注册账号。

## 9. 与 ESP32 圆屏的关系

沿用相同的作品、章节和逻辑页关系，但不照搬手机布局。360×360 单点圆屏每屏展示一本作品或一个章节，用明确的上一项、下一项和进入按钮选择，所有关键操作位于圆形安全区。选择动作仍支持“先选再放”，不依赖拖动或复杂手势。

手机的滚动正文在硬件上可拆成多个展示屏；存档仍记录逻辑页和任务成果，不把手机滚动距离或手机页码当成跨设备进度。具体图文容量需按实际屏幕物理尺寸验证。

## 10. 建议实施顺序与验收

第一步先补内容层级和独立进度，将现有野餐故事归入第一章，再加入同一作品的第二章，验证目录、续读和章节结束后的返回方式。

第二步加入总书架和另一部作品的短章，验证换书不会串进度、角色、声音或日记，并验证可以使用不同互动组合。

第三步根据真实内容数量，再决定是否需要搜索、分类、章节下载管理与更多日记版本。不提前建设内容管理后台、账号系统或自动生成长篇故事。

核心验收：作品 A 中断后转读作品 B，再返回 A 可继续；某章重玩不影响其他章及原日记；第一页返回目录，书架始终直达；完成后不自动续播；不同章节角色和道具不串场；原有存档无损迁移；矮屏的封面、章节选择、阅读和日记均可操作。
