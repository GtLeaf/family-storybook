# 开发路线与验收

版本：v0.3｜2026-10-19

## 1. 技术方向

React + TypeScript + Vite，纯静态应用，无账号、后端和运行时大模型。内容、状态规则、浏览器呈现分离，Zod 校验存档，localStorage 保存本机进度。使用固定内容 ID 与槽位 ID，为未来固件提供语义明确的迁移输入。

字体、图标和插画为本地资源；浏览器朗读使用设备已有中文语音，无在线 TTS 服务密钥。产品交互不输出实现细节。

## 2. 执行阶段

A：优化手机产品与交互规范，保留 v0.2 到 archive。
B：搭建配置驱动故事与可校验存档，完成所有交互。
C：接入插画、声音、响应式页面与异常处理。
D：类型、静态检查、生产构建、状态测试、浏览器端到端验证与视觉检查。
E：真实手机和家庭试用，独立于开发自测；结果填入 07 验证记录。

不承诺旧版 15—24 人日估算仍适用，后续正式配音、内容扩展与硬件分别估算。

## 4. 验证边界

自动验证重点：状态转换前置条件、合流、物品唯一性、交换、存档损坏/语义不一致/版本不兼容；浏览器验证双分支、刷新、暂停、家长设置、清除和移动布局。

浏览器模拟移动视口不是实体手机验收；不把开发者操作通过当成儿童可用性或市场需求证明。Safari/WebKit 模拟和 Chromium 各执行代表流程；微信内置浏览器与设备中文语音听感需后续真机试用。

## 5. 资产和性能

当前屏先加载，后续场景预取；本地 WebP 插画与子集字体。首屏与全章体积以 build 实际文件及浏览器网络记录为准，不用未经测量的“秒开”宣传。源插画放 docs/assets，发布仅 public/art 中的优化版本。

静态 dist 可部署到支持 HTTPS 的托管；此次交付以本地预览和可构建产物为准，不自动创建收费云资源或公开发布。
