# 林边寻物：角色与道具遮挡预览

2026-10-19，用户要求本地拼接，未使用网络图片生成。

输出：[woodland-search-with-items-and-characters-v1.png](woodland-search-with-items-and-characters-v1.png)，1536×1024。
