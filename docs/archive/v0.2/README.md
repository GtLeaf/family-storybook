# 维尼森林亲子可玩绘本 · 项目方案

文档版本：v0.2｜编制日期：2026-10-19｜当前阶段：方案草案，尚未开发

面向 4—7 岁儿童和家长的一本可玩的故事书。每次用约 10—15 分钟，一起发现森林里的小问题，通过探索、选择和摆放，让故事继续。

项目代号：`pooh-family-storybook`。产品工作名《维尼森林·一起的小冒险》仅供内部讨论，尚未完成名称及商标核查。

## 本版已采用的规划假设

- 年龄：4—7 岁为核心，4—5 岁由家长协助，6—7 岁可更多自主操作。
- 已确认的设备目标：ESP32 原型设备，360×360 圆屏、单点触摸。
- 形式：先做网页原型，但从第一版就以 360×360 圆形有效区域为设计基准；手机、平板和电脑承载同一设备画面。
- 地域：先按中国大陆的小范围亲子试用设计；不等同于已具备商业发行条件。
- 首版：1 个章节、3 个场景、3 个角色、3 类交互，包含旁白、两次可跳过的亲子对话及本机存档。
- 视觉：原创暖棕布偶与纸本森林；不采用迪士尼素材，也不直接使用 Shepard 原插画。
- 内容：首章是使用原著角色的原创支线，不冒充原著章节或原文翻译。

ESP32、分辨率、圆屏与单点触摸已由用户确认。其余是待评审的规划选择；芯片具体型号、屏幕物理尺寸、扬声器和存储容量尚未确认。暂不接入账号、支付、云端服务或实时 AI。

交互硬约束：不依赖拖动；点位置再确认；单屏一个主要动作；底部一个大按钮；长台词拆成短句；关键目标全部位于圆屏安全区。

## 首个可评审成果

先做《风吹走的野餐》完整体验，验证三个问题：孩子能否理解操作、家长是否自然参与、故事能否愉快结束。通过后再决定是否扩展成系列。

本次交付仅为方案文档；尚未制作界面原型、游戏代码或设备固件。优先阅读 [ESP32 圆屏迁移与交互约束](docs/06-ESP32圆屏迁移与交互约束.md)。
