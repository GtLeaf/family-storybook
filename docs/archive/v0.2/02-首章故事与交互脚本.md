# 首章故事与交互脚本：《风吹走的野餐》

版本：v0.2｜日期：2026-10-19｜性质：原著角色的原创支线脚本

以下中文旁白和对白均为本项目新写草稿，不是 Milne 原文引述，也不是现有中文译本。角色命名暂供内部策划使用。

## 1. 制作参数

- 角色：维尼、小猪、屹耳，共 3 位。
- 场景：林边小路、大树旁、背风草地，共 3 张主背景。
- 叙事节点：S01—S09，共 9 个逻辑状态；长旁白拆为多个圆屏短句子页，不能将整段文字塞入一屏。
- 设备基准：360×360 圆屏、单点触摸；布局与短文案以第 06 份文档为准。
- 核心物品：杯子、餐巾、篮子、3 块压垫石；结尾用 3 份餐具和 2 件装饰复用摆放机制。
- 三类交互：点击寻找、点选并确认对话、点选槽位并确认摆放；不依赖拖动。
- 时长：亲子共玩约 10—15 分钟，实际以试用为准。
- 两个对话分支均合流；不增加角色好感度、道德分或隐藏坏结局。

## 2. 页面流程

```text
S01 风来过了 → S02 找回野餐物品 → S03 出发去找朋友
     → S04 听见屹耳的担心 → S05 选择陪伴的方式
     → S06 固定野餐垫 → S07 选自己的座位
     → S08 一起开餐 → S09 冒险日记
```

S02 的第一次有效收集后进入独立亲子邀请页 A；S05 的分支回应播放后进入独立亲子邀请页 B。两处邀请都可直接继续，不改变后续通关条件。

## 3. 分页脚本

以下保留完整故事稿，设备显示需按短句拆页。按钮使用下列短标签，覆盖正文中的较长意图描述：

| 节点 | 圆屏主按钮 |
|---|---|
| S01 | 来找找 |
| S02 | 找齐后“出发” |
| S03 | 找朋友 |
| S04 | 怎么陪他 |
| S05 | 就选这个 |
| S06 | 放这里；完成后“继续” |
| S07 | 放这里；餐具齐全后“开餐吧” |
| S08 | 记下来 |
| S09 | 回书架 |

### S01 · 风来过了

**场景**：林边小路。小猪望着被吹散的野餐物品，维尼看着手里的野餐清单。几片树叶缓缓落下。

**旁白**：
> 今天，维尼和小猪准备去野餐。风也来了。它来得很快，走的时候，带走了几样没打算出门的东西。

**维尼**：
> 我想，杯子一定没有长脚。至少，刚才还没有。

**小猪**：
> 我们一起找找吧。

**操作**：孩子点“我们来找找”。首次播放时，短手势示意指向该按钮，完成后不再重复。

**推进**：进入 S02。旁白不强制锁定按钮；提前继续会停止当前句，避免跨页叠音。

### S02 · 找回野餐物品

**目标**：收集杯子、餐巾、篮子，顺序不限。

| 物品 | 画面线索 | 点击后的反馈 | 状态变化 |
|---|---|---|---|
| 杯子 | 草丛露出杯柄，旁边有一片叶子 | 小猪：“原来你躲在这里。” | 杯子进入收集区，对应热点停用 |
| 餐巾 | 树根旁露出一个布角 | 维尼：“一块很会旅行的餐巾。” | 餐巾折好进入收集区 |
| 篮子 | 灌木边露出提手 | 小猪：“这下，东西有地方放了。” | 收集区呈现装好的篮子 |

物品直接可见，不需要先点击灌木才能解锁。装饰热点只会发出轻响或摇动，不额外生成任务。重复点击已收集位置不重复计数或播放长台词。

**亲子邀请页 A**：第一次收集完成、角色短台词结束后出现：
> 一起看看：你从哪里看出风来过？

圆屏显示“风来过哪里？”，故事与无操作提示均暂停；底部只有“继续找”。可以讨论，也可以立即继续。原问题可作为旁白或家长读台本，不与三个寻找目标同时挤在一屏。

**帮助**：第一层旁白“看看露出一点点的东西”；第二层显示剩余物品轮廓；第三层点亮一个尚未收集位置。帮助不自动代替孩子完成点击。

**完成**：3 件齐全后出现“出发”。此前按钮不显示，不出现无法理解的灰色按钮。

### S03 · 出发去找朋友

**画面**：装好的篮子放在路边，维尼和小猪并肩。

**小猪**：
> 屹耳也许想和我们一起。

**维尼**：
> 好主意。篮子里，还有一个朋友的位置。

**旁白**：
> 他们沿着小路往前走。风小了一点，树影轻轻晃着。

**操作**：点“去大树旁”。进入 S04。页面内可重听，不要求走路连点。

### S04 · 听见屹耳的担心

**画面**：大树旁，屹耳坐着，旁边的野餐垫有一角被风掀起。维尼与小猪停在适当距离。

**小猪**：
> 我们来请你一起野餐。

**屹耳**：
> 谢谢。我只是想，风也许还会回来。到时候，垫子会飞，杯子会倒。

**维尼**：
> 嗯。那我们先不着急打开篮子。

**操作**：点“我们可以怎么陪他？”进入 S05。

表现担心而非制造威胁：不出现惊吓音、暴风、落泪特写或夸张失败画面。

### S05 · 选择陪伴的方式

**选项 A**：圆屏标签“听一听”；完整含义“先听他说说”。

**维尼**：
> 你愿意告诉我们，最担心什么吗？

**屹耳**：
> 我不想刚坐下来，就又得追着垫子跑。

**小猪**：
> 那我们想想，怎么让垫子待在原地。

**选项 B**：圆屏标签“陪一会儿”；完整含义“在旁边陪一会儿”。

**旁白**：
> 他们在屹耳旁边坐了一小会儿。没有谁急着说下一句话。

**屹耳**：
> 谢谢你们等我。也许，我们可以先把垫子压住。

**共同行为**：旁白提示“风还有一点，不过我们可以一起想办法”。这句话不自动启动下页。

**亲子邀请页 B**：
> 如果是你，希望有人听一听，还是陪你坐一会儿？也可以有别的办法。

圆屏问题拆为“你想怎样被陪伴？”及“听一听，还是陪着？”两个短句，允许逐句重看；底部只有“继续故事”。不要求在设备上提交答案，选择任何分支、讨论或立即继续均可进入 S06。

**选择规则**：中央两个大选项纵向排列；点选只高亮并试听，底部“就选这个”单独确认。确认后锁定该次选择，防止连点触发两段对白。重玩章节可以选另一条。

### S06 · 让垫子稳稳待着

**画面**：沿用大树旁背景，把垫子放在靠树的背风处；一角已有篮子压住，另外 3 个角翘起，各有一个清晰轮廓标记。

**小猪**：
> 篮子压住了一角。这里还有三块石头。

**操作提示**：
> 点一个翘起的垫角，再点“放这里”。

**玩法**：程序自动拿出下一块石头，孩子只需点一个空标记，再点底部“放这里”。3 个标记均为大触摸区域，顺序不限。已经占用的标记停用；点击背景不落位，保留当前选择，也不重置进度。石头来源只展示为当前物品图，不另设可操作托盘。

**每次成功**：相应垫角轻轻落平，播放短布料声。前两次无需长对白。

**完成台词**：
> 屹耳：现在看起来，好像可以坐一会儿了。
>
> 维尼：正好。我已经准备好坐一会儿了。也准备好吃一会儿。

**推进**：3 处均固定后出现“摆好野餐”，进入 S07。此页讲的是画面内的小任务，不提示儿童外出搬石头。

### S07 · 选自己的座位

**画面**：背风草地。圆屏中部保留野餐垫，3 个餐具位与 2 个装饰位分两行；不把角色、托盘和五个自由拖动物品同时放入小屏。角色主要在对白子页出现，布置子页用简化头像标记。

**旁白**：
> 垫子稳稳地待住了。现在，给每位朋友摆一份餐具吧。位置由你们决定。

**物品**：3 份带角色标记的餐具、1 朵纸花、1 片装饰叶，共 5 件。餐具用轮廓与角色图样区分，不只依赖颜色。

**规则**：
- 按固定顺序每次展示一份餐具，孩子从 3 个未占用餐具位中选一个，再点“放这里”；摆放记录为物品与槽位的对应关系。
- 三份餐具完成后，底部主按钮变为“开餐吧”；菜单可进入“加装饰”或“调整位置”，不强制完成装饰。
- 装饰模式每次展示纸花或叶片，从 2 个装饰位中选一个，再确认；“跳过装饰”由顶部菜单进入，结束后回到布置总览。
- 调整模式先点已放置物品，再点兼容位置，底部确认；若目标已占用则两物交换，不丢失、不堆叠。
- 3 份餐具未齐时不进入开餐；装饰不影响完成。任何一屏底部只有一个主按钮。

**亲子参与建议**：第一次摆好餐具后用一句独立短字幕“请家长也摆一样”，不叠加弹窗；点底部“继续摆”后进入下一件物品。不强制交换设备，不检查是谁操作。

### S08 · 一起开餐

**画面**：保留 S07 的实际布局，三个角色就座。屹耳仍然是安静的表情。

**小猪**：
> 东西找到了，垫子也没有飞走。

**屹耳**：
> 风还在。不过，这里挺好的。

**维尼**：
> 嗯。我喜欢东西待在该待的地方。比如，朋友在旁边。

**旁白**：
> 这一天没有完全照计划发生。可他们还是坐在了一起。

**操作**：点“把今天放进故事书”，进入 S09 并保存完成状态。

### S09 · 冒险日记

**内容**：以本次野餐布局为画面，显示固定事实性记录：
> 今天，我们找回了野餐用品，还一起把垫子固定好了。

**离屏邀请**：
> 要不要在家里找一个舒服的角落，摆一场小小野餐？也可以改天再玩。

**按钮**：底部只有“回到书架”；顶部菜单提供“再摆一次”。首版不默认显示“下一章”，也不出现分享、购买、连玩奖励或倒计时。

“再摆一次”从 S07 的已保存槽位布局继续，调整后重新确认会更新日记；“重玩故事”在书架由家长或家庭主动选择，清楚提示将覆盖本章进度。

## 4. 存档与中断

| 状态 | 保存时机 | 恢复行为 |
|---|---|---|
| 当前节点／句子 | 进入每一节点／短句后 | 回到有效短句，旁白等待用户主动恢复 |
| 已收集物品 | 每次有效收集后 | 已找到物品不再出现，剩余目标继续可找 |
| 对话选择 | 确认时 | 所选分支固定；若对白未完成，从该分支开头重听 |
| 已摆石头 | 每次有效落位后 | 占位保持，石头和目标一一对应 |
| 野餐布局 | 每次落位后 | 按槽位 ID 恢复，避免将浏览器像素写入存档 |
| 书签已处理 | 关闭或继续后 | 不反复弹出；重玩章节时重置 |
| 章节完成 | S08 确认后 | 书架可打开日记或明确选择重玩 |

上表保存时机指内存状态更新；网页可及时写本机存储，ESP32 在节点结束、明确退出、休眠前等检查点提交稳定快照，不能每次触摸都擦写 Flash。突然断电只承诺恢复到最近成功提交的检查点，未提交操作可能需要重做。

网页切到后台、设备息屏或进入暂停菜单时暂停旁白和无操作提示；回到前台或唤醒后由用户点“继续”。不得自动跳过尚未操作的任务。存储失败时允许玩完，并在家长侧说明“本次进度可能无法保留”。
