# ESP32 后续迁移与交互约束

版本：v0.3｜2026-10-19｜后续硬件阶段参考，不阻塞 Web 首版

## 1. 路线

手机 Web 验证内容 → 验证持续内容需求 → 验证专用设备价值 → 确认硬件 → 圆屏适配 → 真机亲子试用。

已知目标：ESP32、360×360 圆屏、单点触摸。未知：芯片、物理直径、触摸/显示控制器、PSRAM、Flash、扬声器、存储、按键及供电。

## 2. 当前应保留的迁移输入

- 稳定章节/节点/语句、物品、分支、座位和装饰 ID。
- 完成条件与状态转换规则；存档保存语义关系，不保存 CSS 坐标。
- 高清插画源文件、分层交互道具和完整文字。
- 状态转换测试及异常场景，用于验证固件具有相同语义。

Web 的 React、CSS、浏览器声音与存储代码不承诺直接复用。不要为未确认硬件引入跨端引擎。

## 3. 圆屏显示阶段再约束

圆心 (180,180)，关键内容外框放入半径约 168 px 的安全区。参考正文 24 原生像素、热点 56—64 px，需按真实直径校准；圆形四角不可放关键内容。

完整句子按设备单屏能力拆分；选择和任务必要时分屏。Web 与固件可采用不同分页，不共享展示页序号；只共享逻辑内容 ID。手机首版不受每行 9 字、两行或固定顶部菜单坐标限制。

## 4. 音频与资源

Web 的浏览器中文语音不是设备端音源。选定硬件后制作/取得可分发的分段音频，或明确由家长朗读。

RGB565 全屏为 360×360×2 = 259,200 字节，双缓冲约 506.3 KiB，额外计入字体、音频、解码与程序。16 kHz/16 bit/mono PCM 每秒约 32 KB。实际选择压缩、分块刷新与存储方案需要真机实测。

## 5. 存档和输入

固件内存即时更新，Flash 按节点切换、退出与休眠等检查点提交；版本校验与旧快照保护；突然断电允许回到最近提交点。

所有必要操作可由单点完成。输入抬起才确认，菜单关闭与唤醒后防止穿透。简单动作是否需要额外确认由实测决定，不强制与手机使用同样按键数量。

## 6. 进入硬件阶段的条件

确认独立设备的目标场景与付费意愿；明确硬件清单；完成屏幕、触摸、声音与资源读取最小验证；再开展与真实物理尺寸一致的儿童试用。
