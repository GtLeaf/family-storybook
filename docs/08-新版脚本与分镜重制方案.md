# 《风吹走的野餐》新版脚本与分镜重制方案

日期：2026-10-20。状态：第一轮已实施，当前 Web 版本 v0.4。

已接入新角色、五处场景、逐句镜头、纸偶动作、分支站位和互动结果延续。初期本地临时配音已由用户交付的 30 段正式逐句录音全部替换；正式重录范围及文件名见 [配音变更与重录清单](09-新版配音变更与重录清单.md)，验证见 [实现与验证记录](07-Web实现与验证记录.md)。下文保留制作设计与参数目标，不把后续增强项视为已完成。

本轮画面采用现有 SVG 道具；开场为风吹后的状态与独立飘叶，完整吹散过程、坐姿和部件表情仍待补素材。圆屏保留单独构图约束，本轮交付为 Web 版。

## 1. 重制方向

保留当前找物品、固定垫角、布置野餐三组互动，以及两种陪伴选择和本地进度。围绕“风打乱计划—找回东西—听见朋友的担心—一起让野餐安稳下来”重新组织视觉叙事。

使用五个有明确用途的场景、现有三张透明角色图和代码动作，制作有镜头节奏的淡彩纸偶绘本。保留现有 12 个逻辑页面，每条路线约 19 个镜头节拍；分支各有两个不同的表演镜头，合计需编排约 21 个镜头。镜头节拍可在同一页内推进，不增加同等数量的翻页按钮。

预计亲子体验约 6—10 分钟，讨论和游戏耗时由家庭决定，不做倒计时。该时长是制作目标，需试玩校准。

## 3. 完整脚本与逐页分镜

镜头时长指视觉动作建议，不包含完整台词播放时间。说话时仅当前角色轻微动作，其他角色停住并朝向他。台词结束后画面稳定等待，不持续循环摇晃。

### P01 / intro：咦，风也来野餐了

背景 A，仅维尼和小猪。三个节拍：

1. 全景停约 1 秒：先看见倾倒的篮子、杯子和翘起的垫角。旁白：“维尼和小猪刚准备好野餐，一阵风就赶来了。”
2. 局部推近：把杯子和餐巾作为观察重点。旁白：“餐巾飘远了，杯子滚到了路边，篮子也倒在草丛旁。”
3. 回到双人中景：维尼朝杯子方向倾一下，停顿；小猪转向路边。维尼：“我想，杯子一定没有长脚。至少，刚才还没有。”小猪：“我们一起找找吧。”

按钮：我们来找找。

素材实施：现有 A 的道具已经画在背景上。第一轮采用风吹后的画面、镜头推近和另加的少量飘叶，不给原图里的杯子、餐巾再叠一份动画。若要完整表现从整齐到吹乱，必须先制作去道具底图、独立道具和垫角；列为后续增强。

### P02 / find：小东西，藏在哪里？

背景 B，单个固定游戏镜头。用短淡切表明换了观察角度，不把 A/B 当成可以精确追踪物体轨迹的连续镜头。

小猪：“杯子、餐巾，还有篮子。看看草丛和树根旁，点一点，把它们找回来吧。”

杯子放左侧树根，餐巾放右下草丛，篮子放右侧灌木。采用既有拼图的遮挡思路，最终坐标按目标屏幕重新校准。角色占中间较小区域，不挡住三个目标。

每次找到，道具从原处离开，进入收集区；背景露出原来位置，前景草叶保留。对应反馈：“原来杯子躲在这里。”“找到一块很会旅行的餐巾。”“找到篮子了，东西有地方放了。”

保留大点击区、帮助与任意收集顺序。相机在游戏期间固定。动画不推迟状态保存，重复点击不重复收集。

按钮：都找到了，三件齐全后出现。

### P03 / wind-talk：你从哪里看出风来过？

背景 B，一个观察镜头，继承已收集状态，不把物品重新放回隐藏点。用品放在收集区或已归拢的篮子旁。

旁白：“东西找回来了。再看看周围，你从哪里看出风来过？是歪向一边的小草，还是晃动的叶子？”

让一片独立叶子轻轻经过，给孩子具体观察线索；不以颜色圈出标准答案。角色停住，留给亲子对话。

按钮：去找屹耳。可立即继续，不记录回答。

### P04 / walk：还有一个朋友的位置

背景 C，两个节拍，屹耳尚未登场。

1. 近处双人镜头。小猪：“屹耳也许想和我们一起。”维尼：“好主意。我们给他留个位置。”
2. 两人朝远处大树走一小段：镜像调整朝向，沿路位移并略微缩小，轻微交替摇摆；停在仍清楚可辨的位置。旁白：“他们收好用品，沿着小路去找屹耳。风小了一点。”

篮子跟随维尼；折好的垫子、杯子、餐巾可以在转场中归拢，不增加打包操作。没有背影图时，三分之四角色短距离斜向移动即可，不演完整背对观众的远行。

按钮：去大树旁。

### P05 / worry：屹耳有一点点担心

背景 D，两个节拍。

1. 全景：先看到左侧树旁的屹耳，再让小猪与维尼从右侧走近，留出距离。小猪：“屹耳，要和我们一起野餐吗？”
2. 以屹耳为重点的中景，不把他的低头强行扭成抬头。屹耳：“谢谢。我只是想，风也许还会回来。到时候，垫子会飞，杯子会倒。”维尼停止靠近：“嗯。那我们先不着急。”

担心首先通过低头、独处和停顿表达，不加乌云、哭泣或夸张惊吓。此处垫子尚未铺开，台词描述担心，不在背景里凭空出现现时飞起的垫角。

按钮：我们可以怎样陪他。

### P06 / choice：陪伴，可以有不同的样子

背景 D，一个稳定的三人关系镜头。保持 P05 站位，不重新排成面向观众的一排。

旁白：“我们可以先听他说说，也可以安静地陪他待一会儿。你想试哪一种？”

选项 A：先听他说说。预览句：“你愿意告诉我们，最担心什么吗？”

选项 B：在旁边陪一会儿。预览句：“不用着急，我们就在这里。”

先选中、后确认。两种都有效，不显示优劣、分数或奖励差别。

按钮：就这样陪他。

### P07 / response：有朋友在，就很好

背景 D，两条分支各两个节拍，以距离和动静区分。

**A 倾听**

1. 维尼向屹耳靠近一点，朝向他，轻微前倾；小猪站在侧边听。维尼：“你愿意告诉我们，最担心什么吗？”
2. 镜头轻轻偏向屹耳；屹耳身体微动后停下。屹耳：“我不想刚铺好垫子，就又得追着它跑。”小猪：“那我们想想，怎么让垫子待在原地。”

**B 安静陪伴**

1. 两位朋友移动到屹耳旁边，三者朝向同一片空地，保持舒服距离。旁白：“他们留在屹耳旁边。没有谁急着说下一句话。”旁白后留约 2 秒安静，可随时继续。
2. 角色停止动作，屹耳轻微转向朋友或小幅前移，不能用整图翻转冒充抬头。屹耳：“谢谢你们等我。也许，我们可以先把垫子压住。”

本轮将“坐一会儿”改成“待一会儿”，适配当前站姿资源。以后若补坐姿，可替换表演和对应文案，逻辑选择 ID `stay` 保留。

按钮：留一点时间聊聊。

### P08 / companion-talk：你想怎样被陪伴？

背景 D，一个静止镜头，继承刚选分支的站位；避免分支刚演完立刻重置。

旁白：“如果是你，希望有人听一听，还是安静地陪一会儿？也可以有别的办法。不知道也没关系。”

主问题突出，其他说明放轻；不弹出强制答题。停止角色说话动作，留给现实中的两个人。

按钮：一起想办法。

### P09 / stones：让垫子稳稳地待着

背景 E，两个节拍。

1. 转场建立新位置，三人先短暂出现于外围。旁白：“他们绕到大树背风的一面，重新铺好垫子。”篮子落在一个角上。小猪：“篮子压住了一角。再用三块石头，把另外三个角也固定好。”
2. 切至固定游戏镜头，以垫子为主体，角色缩至上缘或退出镜头。三个未固定角轻微翘动，点击后石头到位，对应角停止；全部完成后维尼、小猪朝向屹耳，屹耳靠近一点。

任务提示：点一下垫角，放上一块小石头。

完成反馈：屹耳：“现在看起来，好像可以安心待一会儿了。”

仍然直接点角，无拖拽、无时机判断；可动的是垫角视觉，点击区域位置不动。

按钮：摆好我们的野餐。

### P10 / picnic：这里，给你留了个位置

背景 E，一个固定游戏镜头，保留上页的篮子和三块石头，不能进入布置页就全部消失。

旁白：“给每位朋友留一个位置。你摆一份，也可以请家长摆一份。再添一朵花、一片叶子，就是你们的小小野餐。”

保留选空位、交换、可选装饰的玩法；语义统一为“餐具标记朋友的位置”。角色小像只作标记，避免被理解成把朋友放进盘子。可用独立餐具图＋小姓名签，和外围全身角色明确区分。

放置一份后，对应朋友朝那个位置靠近一点作为反馈；最后的全身人物布局读取同一份座位顺序。采用沿垫子远侧和两侧的浅弧形站位，兼容当前四足屹耳与直立伙伴。若日后要求真正围坐和进餐，再补相应姿态；本轮不压扁、截腿模拟坐姿。

按钮：开餐吧，位置齐全后出现。

### P11 / ending：朋友在旁边，这里挺好的

背景 E，两个节拍。

1. 从游戏近景略拉开：显示按实际顺序站在垫边的朋友、餐具、装饰和全部固定物。风叶从画面外缘掠过，垫角保持不动。小猪：“风又来了。看，垫子没有跑！”
2. 镜头以屹耳及两位伙伴为重点。屹耳：“风还在。不过，这里挺好的。”维尼：“嗯。朋友在旁边，东西也不用追了。”旁白：“这一天没有完全照计划发生。不过，他们还是一起开始了野餐。”

让开场的风再次出现，直接验证孩子刚才的帮助。三位角色平静靠在同一组构图里，不突然跳舞或齐声庆祝。

按钮：把今天记下来。

### P12 / diary：我们的小小野餐

一个静态纪念镜头，复用最终布局，不重新生成预设合影，不把用户选过的装饰换掉。

旁白：“今天，我们找回了野餐用品，也让垫子稳稳地留在原地。每位朋友，都有了自己的位置。”

提供回书架、再摆一次、上一页。离屏邀请作为可选文字或独立可播放语音：“下次，也可以和家里人一起摆一场小野餐。”不自动开启下一章。

## 4. 代码动作与镜头规范

| 动作 | 初始制作参数 | 使用位置 |
|---|---|---|
| 移动 | 角色位移，旋转约 ±2°，小幅上下起伏；维尼慢、小猪轻快、屹耳幅度最小 | 赶路、靠近、站到位置旁 |
| 朝向 | 用水平镜像确认看向谁；只在转向需要时变化 | 对话、邀请、倾听 |
| 发言 | 说话者倾斜约 1—2°或单次轻微前探，听者静止 | 按语句切换发言者 |
| 安静陪伴 | 先靠近，再全部停住，保留短暂停顿 | stay 分支、讨论页 |
| 物品收集 | 从目标处短距离移向收集区并淡出，约 0.3—0.5 秒 | 找东西 |
| 物品落位 | 道具短弧线运动、落位后稳定，约 0.2—0.4 秒 | 石头、餐具、装饰 |
| 风 | 少量独立叶片单次经过；需要时局部垫角变形 | 开场、固定前、结尾 |
| 相机 | 叙事页适度推近或重新构图；游戏页锁定 | 情绪重点、远近转换 |

以上是起始调参值，不是硬件性能承诺。镜头通常在约 0.4—0.8 秒内切换，不持续推拉。少用透明度变化来突出发言者，避免淡彩线条难辨。

位置、朝向、身体摇摆分别控制，避免镜像覆盖移动变换。镜像中心与落脚点固定，屹耳按四足接地线定位。保持每个场景内身高和透视关系，不为了放大脸而让同一全景中的角色忽大忽小。

## 5. 分镜推进、音频与回退

- 听故事模式按语句或音频段完成事件推进页内镜头。v0.3 整页 MP3 不能直接获知说话者；v0.4 已改用逐句本地临时音频，改词只需重录对应句子。原整页音频保留在 v1 目录供复用。
- 不用未经验证的固定秒数追赶音频。音频失败或家长读模式，可点击明确的“继续讲”推进页内节拍；不要把整张画面变成隐藏翻页热区。
- 全部正文提供可展开的文字阅读；镜头聚焦时只突出当前一句，不用自动滚动长文字抢走视线。每页内部镜头可跳到稳定的最终画面，游戏无需等待长动画。
- 顶部“上一页”仍按逻辑页面回退。叙事页可提供重看这一幕；回看任务页时直接恢复已收集、固定和摆放结果，不再演一次操作或发放反馈。
- 换页、暂停、退出、切后台和重选分支时，取消上一镜头的声音与动作。减少动态模式直接显示每个节拍的稳定构图，保留必要信息。
- 存档记录任务成果、选择和逻辑页，不保存动画中间坐标。刷新后重建这一页并恢复结果；镜头重播不重置任务，也不能阻止完成后的回看。

## 6. 画幅与 360×360 圆屏预留

当前五张背景为 1536×1024（3:2）。中心正方形裁切保留原图 x=256—1280；现有寻物拼图的篮子位置靠右，不能直接套裁切，否则目标会被切掉。未来圆屏还会进一步丢失正方形四角。

Web 先按当前手机版展示，所有角色和热点使用归一化位置；每个背景另记相机裁切和目标安全区，不把一套绝对坐标同时用于所有画幅。圆屏采用单独构图：装饰背景可裁切，人物、目标和按钮须重排。

360×360 圆屏方案：

- 重要角色和道具放圆内，不能只检验正方形外框；完整热点外框也必须落在圆内。
- 寻物三个目标重新分布，必要时把三个藏匿位置做成分屏近景；避免缩小目标勉强塞进圆屏。
- 选择采用大尺寸文字按钮，必要时独立一屏；操作只有单点点击，无滑动拖拽和多指要求。
- 人物对话以双人中景或单人重点构图呈现，三人全景只在建立空间和结尾使用。
- 动作描述保留时间、位移、旋转、朝向等语义参数，ESP32 单独实现播放；不承诺复用 CSS、整页布局或媒体解码方案。

## 7. 资源缺口与制作顺序

### 第一轮：可用现有角色完成

1. 接入三张新角色和五张背景；确定透明边缘、尺寸、接地点与纸色。
2. 准备可独立移除的杯子、餐巾、篮子、石头、垫子、叶片、花；寻物保留前景遮挡层。现有 SVG 可验证逻辑，但线重与色彩需要和新水彩场景协调。
3. 垫子用可控制三角的平面或分层素材，篮子与三石头跨页保留；不要直接把开场已吹起的垫子切片用于全部俯视场景，需匹配 E 的透视。
4. 制作移动、朝向、发言、靠近、停顿、道具落位与相机切换这些通用动作。
5. 先做 intro→find、worry→choice→response、stones→picnic→ending 三段样片，验证事件、情感、互动结果都能在画面中看见，再补全过场与讨论页。
6. 最终锁定台词后重录发生变化的语音，建立新音频版本与镜头映射，避免旧音频读出“坐下”而画面仍站着。

### 后续增强

- 干净的开场底图与分离道具，完整演出风把东西吹乱的过程。
- 两位伙伴坐姿与屹耳伏卧或休息姿态，用于真正的陪坐和进餐镜头。
- 可换表情、头部、耳朵或手臂层，用于更细的情绪表演。

这三类增强不是当前脚本成立的前置条件。先保证角色何时登场、看向谁、为何靠近、互动结果如何影响故事都表达清楚。

## 8. 验收依据

- 关掉声音看开场，能辨认野餐被风打乱；屹耳不会提前出场。
- 仅看画面也能区分倾听与安静陪伴，两种分支都自然走向一起解决问题。
- 收集后物品不再留在隐藏点；压住的垫角停止；布置与结尾保留篮子、石头、座位顺序和装饰。
- 结尾风再次出现时，画面直接展示垫子已经稳住，回应孩子的操作。
- 当前角色全程保持自然身形，四足屹耳不做直立或滑坐伪装。
- 找物、放石头、摆餐具时相机和触摸目标稳定；快速点击、返回、重选、刷新都不丢任务成果，不残留旧台词或旧动作。
- 提案落地后分别验证手机与圆屏构图；圆屏热点须通过真实尺寸和触摸测试，不能由 Web 测试结果替代。
